# Series plan

About 10 games, each a pre-printed booklet played with one d6 and a pencil, for grades 6–10.
Every game is organised around the five domains:

1. Algorithms & Design
2. Programming
3. Data & Analysis
4. Systems & Security
5. Computing & Society (with AI integrated across domains)

## Progression model (not decided)

| Option | How it works |
|---|---|
| By grade | Games 1–3 for grade 6, rising to games 8–10 for grade 10 |
| Spiral | Every game covers all five domains, each one level deeper than the last |
| Themed | Each game is a different world built around one domain |

Leading suggestion: a **spiral with a new setting per game**. It keeps the proven five-floor structure, each
game stands alone for a teacher, and the website can present the games in order.
